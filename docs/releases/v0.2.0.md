## AnyPlay Launcher 0.2.0

The launcher is now called **AnyPlay Launcher**, it has an online area, and from this release on its updates are signed.

### New name

AnyPS5 Launcher is now AnyPlay Launcher. AnyPS5 is still the engine your games run on. Installing the new Setup over an old install upgrades it in place and keeps your settings, library and saves. Your data folders and `anyps5://` links keep their old names on purpose, so nothing breaks.

### Online with friends

- Select your profile on the home screen to open the **Online** area. Sign in or create an account in your browser, with a passkey or an e-mail code.
- See which friends are online and what they play. Send and accept friend requests and game invitations, and block or report someone.
- Start a **party**, invite friends to it and send messages.
- Trophies are recorded with your account. A friend's page shows how many trophies they have, by grade. Names and pictures stay on your PC, and **Who Sees Your Trophies** on the Account page decides who sees them.
- Your playtime per game and day is recorded with your profile.
- **Hide Your IP Address** sends all traffic through a relay, so other players never learn your address. Games may respond a little slower.
- New builds use the AnyPlay test cloud at `https://anyplaynet.com` by default. It is a test: expect resets and downtime. You can enter another cloud under **Online, Cloud**.
- No real game plays online yet. Games start offline until your AnyPS5 toolkit carries the network bridge.

### Signed updates

From now on every update is signed. The launcher installs a new version only if its signature matches the key built into the launcher, the offer has not expired, and the file is exactly the one that was signed. If anything is wrong, it skips the update and keeps what you have. Launchers up to 0.1.3 do not check a signature, so they take this release one last time the old way, and every launcher after that checks.

Every file in this release also has a build attestation. You can check one with `gh attestation verify <file> --repo anyplay-gg/launcher`, and `SHA256SUMS.txt` lists the checksums. The files are still not code-signed, so Windows SmartScreen may ask once.

### Other changes

- Every package now carries the licences of all third-party code (`THIRD-PARTY-LICENSES.txt`).
- The release also has `AnyPS5-Launcher-0.2.0-x64.exe`, the same program as the portable exe under the old name, so copies of 0.1.2 and 0.1.3 can find their update. You do not need it.

### Downloads

- Windows: `AnyPlay-Launcher-0.2.0-Setup.exe` (installer, no administrator rights needed) or `AnyPlay-Launcher-0.2.0-x64.exe` (one file).
- Linux: `AnyPlay-Launcher-0.2.0-x86_64.AppImage` or `AnyPlay-Launcher-0.2.0-linux-x86_64.tar.gz`. The Linux build does not update itself yet.
